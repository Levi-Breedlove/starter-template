# Contributing

Start from the current project instructions and mapped handoff. Tie a change to an observable requirement or a reproduced defect. Preserve established application files, task ownership, infrastructure state and delivery controls. Include the candidate revision, actual check outcomes, remaining limitations and any recovery steps in the pull request.

Use a topic branch and the repository's review controls. For framework maintenance, run the complete standard-library regression suite and source repository checker. In an adopted application, run its own tests, the installed workflow's `doctor` and its mapped specification checks. Record fresh evidence for affected behavior.

## Private use and redistribution

This repository is intended for authorized private use. No open-source license has been selected. Obtain the owner's permission before redistributing the template or publishing it. The official AWS toolkit, emulator and other separately installed components retain their upstream terms.
