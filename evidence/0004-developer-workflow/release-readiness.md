## Developer onboarding after promotion

Choose **Use this template → Create a new repository**, leave **Include all branches** clear, then open **Code → Codespaces** in the new repository. Open the configured Codex client at its root and type **`start`**. The first consultation should establish the outcome and users, inspect known constraints and save settled decisions. Returning developers use `start` or `resume`. Codespaces is the observed Linux environment. Linux, macOS and WSL are documented development targets with Python 3.10+, Git and a configured Codex client. This run did not exercise macOS or WSL.

After the candidate passes the native smoke and applicable PR review, verify the distributed commit, update the repository's default branch to the verified `template` branch, and read back its identity. Under **Settings → General**, verify **Template repository** is selected. If it is clear, select it after verifying the default branch. Tag the accepted distribution commit.
