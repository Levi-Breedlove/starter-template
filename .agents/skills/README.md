# Optional future skill packaging

No `SKILL.md` package is supplied or installed here. The requested scaffold was designed independently of the owner's personal skills and is usable through `AGENTS.md` and explicit workflow procedures.

If later packaging helps repeated invocation, package only the repository's original workflow entry points with concise discovery metadata and references to canonical documents. Avoid maintaining a second copy of the procedures or specifications. Test discovery and behavior on the supported client before claiming automatic activation.

This directory is not a place to copy AWS toolkit skills. Keep official AWS Core and AWS Data Analytics plugin identities and supported update paths. A user task can opt out of skills and use current official documentation directly.

Optional packaging is deferred in the [roadmap](../../docs/implementation-plan.md). Official [Codex skill documentation](https://learn.chatgpt.com/docs/build-skills) describes the product format; it does not create a task requirement to use skills.
