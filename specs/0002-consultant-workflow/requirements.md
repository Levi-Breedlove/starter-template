# Requirements: executable consultant workflow

**Route:** Quick, with one combined specification review.  
**Mode:** Brownfield maintenance of the existing bootstrap.  
**Scope source:** The user's request to correct the repository so Codex leads AWS consultation, interviews adaptively, creates connected artifacts, supports both adoption modes, and uses neutral content.  
**Authority:** Repository edits and offline verification are authorized. This record does not imply account access, cloud deployment, paid background trials or user approval of an application architecture.

## Goal

Make the bootstrap usable from a rough idea and durable between sessions. Put deterministic initialization, state, dependency, freshness and path behavior in code. Keep engineering judgment and the interview in Codex, supported by focused procedures.

## Decisions already supplied

The user selected Codex, the official AWS toolkit identities, both adoption modes, consultant-led interviewing, preservation of accepted architecture, and neutral repository content. The task does not need another product questionnaire. The later question about a compiled backend asks for an assessment; it does not require a language rewrite before this implementation is tested.

## Scope limits

This slice does not implement a worker scheduler, paid autonomous service, live model benchmark, native UI, plugin updater or AWS application. It supplies a tested local workflow seam that can support those later when justified. Human/model judgment still determines semantic sufficiency and whether recorded observations are truthful.
